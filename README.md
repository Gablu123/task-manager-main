# 📱 React Native Task Manager App

## 🚀 Project Overview

This is a cross-platform mobile application built using **React Native with Expo**, designed for fast development and production-ready deployment on both Android and iOS platforms.

The project focuses on clean architecture, offline support, and real-time updates and syncing using firebase and libraries.

---

## 🏗️ Architecture

The application is built using **Expo (React Native)**, which provides:

- Fast development and prototyping
- Simplified build and deployment process
- Cross-platform compatibility (Android & iOS)
- Easy access to native features with minimal configuration

---

## 📚 Libraries & Tools Used

- **@reduxjs/toolkit**  
  Used for scalable and efficient state management.

- **react-redux**  
  Connects React components with the Redux store.

- **expo-notifications**  
  Used for sending push notifications via Firebase.

- **expo-sqlite**  
  Provides local persistent storage for offline usage.

- **@react-native-community/netinfo**  
  Detects network connectivity (online/offline status).

## ⚙️ Getting Started

### 1. Clone or Download the Repository

```bash
git clone https://github.com/Gablu123/task-manager-main.git
# OR download ZIP and extract
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Start the Development Server

```bash
npx expo start
```

### 4. Run the App on Device

- Press **`s`** to switch to **Expo Go mode** (not development build)
- Install **Expo Go** from Play Store / App Store
- Scan the QR code from the terminal
